# Harshit Mehra — Portfolio Website

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript. No build tools or paid services are required.

## 1. Preview locally
1. Extract this ZIP file.
2. Open the `harshit-mehra-portfolio` folder in Visual Studio Code.
3. Open `index.html` in your browser. For a smoother workflow, install the free **Live Server** extension in VS Code, right-click `index.html`, and choose **Open with Live Server**.

## 2. Personalise before publishing
Make these changes:
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real professional email address. Search for `YOUR_EMAIL` to find it.
- Add your photograph as `assets/profile.jpg`. Use a clear, professional head-and-shoulders photo. Keep the filename exactly `profile.jpg`. If you do not add a photo, the site displays the HM initials fallback.
- Add your LinkedIn URL if/when you create your profile.
- Update project cards only after you have completed the projects. Replace the planned/in-progress labels with accurate statuses and add real demo/repository links.
- Review the skills list and remove anything you cannot currently demonstrate.

## 3. Publish free with GitHub Pages
1. Sign in to GitHub: https://github.com/harshitmehra249-hash
2. Create a **new public repository** named `harshitmehra249-hash.github.io`.
3. Upload the contents of this folder (the `index.html`, `style.css`, `script.js`, `assets` folder and this README) to the repository root. Do not upload the outer ZIP as the only file.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. Your website should be available at:
   https://harshitmehra249-hash.github.io

GitHub Pages documentation: https://docs.github.com/en/pages

## 4. Important accuracy notes
- The portfolio intentionally describes you as an aspiring/beginner developer and marks project ideas as planned or in progress. Do not claim professional experience, completed client work, certifications or advanced skills unless they are true.
- The contact button uses an email link (mailto), not a server-backed contact form.
- The site uses Google Fonts when internet access is available; it falls back to system fonts if not.
- Check the website on both mobile and desktop after publishing.

## Files
- `index.html` — page content and structure
- `style.css` — responsive design and visual styling
- `script.js` — mobile navigation, profile-photo fallback and current year
- `assets/profile.jpg` — add your own portrait here
